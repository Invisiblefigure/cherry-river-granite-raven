Мультимедиа

Мультимедиа — это совокупность форм представления информации: текст, графика, анимация, звук и видео.

Основные форматы:

GIF JPEG PNG

🔊 Аудио

Для воспроизведения звука без плагинов в HTML5 применяется тег <audio>.

Пример аудиоплеера (можно заменить на свой файл voice.mp3)

Пример кода:
<audio src="voice.mp3" controls></audio>

🎬 Видео

Для воспроизведения видео в HTML5 используется элемент <video>.

Пример видеоплеера (можно заменить на свой файл video.mp4)

Пример кода:
<video src="video.mp4" width="350" controls></video>
